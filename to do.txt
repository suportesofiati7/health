- Identify conflicts: Find duplicate deployments, outdated builds, legacy configurations, competing hosting methods, and incorrect database connections.
- Establish one architecture: Define a single authoritative workflow: Source → Build → Deploy → Host → Domain → Database.
- Remove legacy systems: Safely eliminate obsolete scripts, configurations, deployments, and conflicting code after verifying dependencies.
- Verify production: Perform a clean build and deployment, confirm the live domain serves the latest version, and test authentication, database operations, editing, deletion, and caching.
- Prevent future conflicts: Standardise development, deployment, and updates so new changes reliably reach production.
- Document everything: Clearly identify the official repository, build/deployment commands, Cloudflare project/account, Supabase project, production domain, and future update procedure.
Final objective: One clean, reliable, fully verified production architecture with no competing deployment systems, outdated builds, or confusing configurations. Audit first, fix safely, and preserve all existing functionality and data.
