# Franciele Sofiati website

Production source for Franciele Sofiati Biomédica’s bilingual static website. Brazilian Portuguese is served at the root; English is served under `/en/`. The site is framework-free: semantic HTML, CSS and native JavaScript modules are compiled into a clean production artifact.

- Canonical origin: `https://francielesofiati.com`
- Node.js: 22.19+ (exact development dependencies are locked in `package-lock.json`)
- Cloudflare Pages deployment: this `health` project is the no-build public static site; keep the management app in its separate Cloudflare project

## Start here

```bash
npm ci
npm run release:check
npm run serve
```

This runs the release validation, builds the deployable artifact and serves it locally. For editable source preview, use `python3 -m http.server 4173`; source partials are fetched at runtime and will not work from `file://` URLs.

Read the [engineering handover](docs/handover.md) for the everyday workflow, [architecture](docs/architecture.md) for ownership, [content workflow](docs/content-workflow.md) for editing, and [deployment guide](docs/deployment.md) before publishing.

## Source of truth

| Concern | Authoritative location |
| --- | --- |
| Brazilian Portuguese page content | Root `*.html` pages |
| English page content | `en/*.html` pages and `en/blog/*.html` articles |
| Shared interface | `partials/` and `partials/pt-BR/` |
| Styles | `css/site.css` |
| Browser behaviour | `js/main.js` and modules under `js/` |
| Canonical site identity | `data/seo.json` |
| Language route pairs | `data/page-pairs.json` |
| Discovery files | `robots.txt`, `sitemap.xml`, `llms.txt`, IndexNow key; generated by `scripts/index-site.py` |
| Deployment output | `dist/`, generated by `npm run build` |

## Key commands

```bash
npm run validate              # assets, PT-BR, SEO and analytics checks
npm run build                 # recreate dist/
npm run release:check         # validate, then build
npm run site:index             # update robots/sitemap/llms and notify IndexNow
npm run site:translate         # update edited bilingual pages
npm run seo                    # complete SEO/link/schema/image audit
npm run screenshots            # interactive screenshot manager
npm run git:publish            # dated git add/commit/push
npm run maintain              # regular indexing, translation, SEO, and build checks
npm run maintain -- --backend # same routine plus Supabase migrations and Edge Functions
```

The build composes partials, fingerprints CSS/JS, creates responsive AVIF/WebP variants and writes `dist/_headers` for local/CI verification. It does not change Cloudflare settings; the live public site remains the separate no-build `health` project.

## Editorial and privacy boundary

Keep treatment information educational. Do not publish diagnoses, prescriptions, promises of outcomes, unverified location details, prices or appointment availability. Suitability, timing, settings, recovery and results must remain consultation-dependent.
